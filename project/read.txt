----
docker-compose.yml (Local / Dev): Dùng lệnh docker compose up để chạy ứng dụng trên 1 máy đơn lẻ (máy cá nhân hoặc 1 Server VPS).

swarm.yml (Production / Cluster): Dùng lệnh docker stack deploy -c swarm.yml <tên-stack> để chạy ứng dụng trên cụm nhiều máy chủ (Swarm Cluster) nối lại với nhau.
